# Online Shopping and Order Management System

## Project Overview

The **Online Shopping and Order Management System** is a C++ project developed as part of the Data Structures and Algorithms (DSA) Open-Ended Lab (OEL).

The project focuses on implementing fundamental data structures and algorithms to manage product records, perform searching and sorting operations, handle shopping cart activities, process customer orders, and maintain data using file handling.

It demonstrates the practical application of data structures in an online shopping environment.

## Objectives

- To understand and implement fundamental data structures in C++.
- To manage product records efficiently.
- To perform searching and sorting operations on product data.
- To implement shopping cart operations.
- To process customer orders using the FIFO principle.
- To handle file operations for permanent data storage.
- To test program functionality using normal and boundary test cases.

## Technologies Used

- **Programming Language:** C++
- **IDE:** Visual Studio Code
- **Compiler:** GCC (G++)
- **Version Control:** Git and GitHub

## Data Structures and Algorithms

The project demonstrates the following concepts:

- **Arrays:** Used to store and manage product and order records.
- **Structures:** Used to organize product and customer order information.
- **Singly Linked Lists:** Used for dynamic product record management.
- **Stack:** Used to implement shopping cart operations.
- **Queue:** Used to process customer orders following First In, First Out (FIFO).
- **Searching Algorithms:** Linear Search and Binary Search.
- **Sorting Algorithm:** Bubble Sort.
- **File Handling:** Used to save and retrieve product records, inventory details, and customer orders.

## Project Modules

| File Name | Description |
|---|---|
| Task1_ProductManagement.cpp | Product management using a linked list. |
| Task2_SearchingSorting.cpp | Searching and sorting product records. |
| Task3_ProductOperations.cpp | Product insertion, updating, deletion, and searching. |
| Task4_ShoppingCart.cpp | Shopping cart operations using a stack. |
| Task5_OrderManagement.cpp | Customer order management using a queue. |
| Task8_FileHandling.cpp | Saving and retrieving product and order records using files. |

## File Handling

The file handling module uses C++ file streams to maintain data permanently.

- `products.txt` stores product records and inventory information.
- `orders.txt` stores customer order information.

Saved records can be retrieved when the program is executed again.

## Testing

The application modules are tested using normal and boundary test cases, including:

- Product registration and display.
- Searching and sorting operations.
- Duplicate product IDs.
- Shopping cart operations.
- Invalid order quantities.
- Insufficient product stock.
- Empty order queue.
- Data persistence after program restart.

Expected and actual outputs are compared to verify program functionality.

## How to Compile and Run

Make sure a C++ compiler (G++) is installed on your system.

Open the project folder in Visual Studio Code and run the following commands in the terminal:

**Example:**

```bash
g++ Task1_ProductManagement.cpp -o Task1
```

Run the executable:

```bash
.\Task1.exe
```

The same procedure can be followed for the other C++ source files by replacing the file name.
